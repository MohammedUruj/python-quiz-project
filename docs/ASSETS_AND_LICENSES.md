# Assets and Licences

All visual assets in this project are **original and generated in code** for this project. No external images,
fonts, icon packs, sounds or third-party libraries are used, and nothing is loaded from external URLs.

| Asset | Source |
|---|---|
| Factory floor, machines, conveyors, forklift and characters | Drawn at runtime on an HTML canvas (`web/js/world.js`) |
| Tyre illustrations and defect overlays | Generated SVG (`web/js/art.js`, `tyreSVG`) |
| Character portraits and selectable avatars | Generated SVG (`web/js/art.js`, `portraitSVG`) |
| Charts (Pareto, histogram, control, scatter, comparison, trend) | Generated SVG (`web/js/charts.js`) |
| Building-cell scene | Inline SVG (`web/js/levels/level6.js`) |
| Favicon | Inline SVG data URI in the HTML files |
| Icons in the HUD and toasts | Standard Unicode emoji, rendered by the player's operating system font |
| Fonts | The system UI font stack (no web fonts are downloaded) |

The company *Qualitrax Tyres*, its products, its people and all data are fictional. Any resemblance to real
companies or persons is coincidental. No copyrighted characters or commercial game designs are reproduced.
